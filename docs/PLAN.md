# «Состав заявки» — план переработки

**Цель:** заменить воронку-расследование «Дело Васи» на компактную воронку из
14 экранов вокруг трёх видео по `docs/SPEC.md`, сохранив инфраструктуру и
адрес выкладки.

**Что переиспользуется:** обёртка Telegram (`src/lib/telegram.ts`), хелперы
(`cn`, `motion`, `env`), схема деплоя, подход к токенам, примитивы `Screen`,
`BottomBar`, `Button`, `Choice`, `ChoiceList`, `Display`, `Prose`,
`SystemLabel`, `ChatBubble`, `VideoSlot`.

**Что удаляется целиком:** `src/scene/*`, `src/features/*`, `src/mechanics/*`,
`src/content/*` (кроме `types.ts`, который переписывается), `src/router/*`,
`src/store/case.ts`, примитивы прежней грамматики дела: `Sticker.tsx`,
`Stamp.tsx`, `DossierCard.tsx`, `LeverMeter.tsx`, `Thought.tsx`, а также
рукописная гарнитура Caveat из зависимостей и токенов.

## Общие ограничения

- `docs/SPEC.md` — канон. Копирайт переносится дословно, включая мат.
- Цвета только из токенов. Хардкод hex запрещён.
- Русских строковых литералов в компонентах нет — весь текст из `src/content/*`.
- Без `any` вне `src/lib/telegram.ts`, без `@ts-ignore`, без `!` для обхода null.
- **Базовые CSS-правила лежат внутри `@layer base`.** Незаслоённый CSS
  перебивает `@layer utilities` Tailwind 4 и молча обнуляет все отступы и
  заливки при зелёной сборке. Это уже ломало проект однажды.
- `BottomBar` прижимается к низу вьюпорта на коротком содержимом (`mt-auto`) и
  остаётся липким на длинном.
- Неактивная кнопка отличается от `ghost` формой, а не только цветом текста:
  пунктирная граница без заливки.
- Контраст: основной текст ≥7:1, второстепенный ≥4.5:1, границы интерактивных
  элементов ≥2.2:1. Считать, а не оценивать на глаз.
- Анимируются `transform` и `opacity`; `prefers-reduced-motion` уважается в
  каждой анимации.
- Файл длиннее 200 строк — разделить.
- Проверка: `npx tsc --noEmit -p tsconfig.app.json`, `npx vitest run`,
  `npm run lint`. Сборку прогоняет оркестратор.
